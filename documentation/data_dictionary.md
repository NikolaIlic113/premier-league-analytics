# Data Dictionary

This document describes the fields used in the Premier League analytical dataset.

The dictionary will be expanded as the data pipeline is developed.

## Match Data

| Field | Description | Data Type |
|---|---|---|
| MatchID | Unique match identifier | String |
| Season | Premier League season | String |
| MatchWeek | Match week | Integer |
| Date | Match date | Date |
| HomeTeam | Home team | String |
| AwayTeam | Away team | String |
| FullTimeHomeTeamGoals | Home goals at full time | Integer |
| FullTimeAwayTeamGoals | Away goals at full time | Integer |
| FullTimeResult | Full-time result | String |
| HalfTimeHomeTeamGoals | Home goals at half time | Integer |
| HalfTimeAwayTeamGoals | Away goals at half time | Integer |
| HalfTimeResult | Half-time result | String |
