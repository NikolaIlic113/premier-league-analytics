# Data Quality

## Objective

The objective of data quality checks is to ensure that the final analytical dataset is complete, consistent and suitable for Power BI analysis.

## Planned Checks

- Missing values
- Duplicate matches
- Invalid dates
- Invalid scores
- Invalid result codes
- Team name inconsistencies
- Unexpected number of matches per season
- Unexpected number of teams per season
- Home/away result consistency
- Historical availability of match statistics

## Historical Limitations

Not all variables are available for all seasons.

Missing historical statistics will be preserved as null values rather than artificially populated.
